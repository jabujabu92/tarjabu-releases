# TarJabu downloads

TarJabu is a free companion app for Escape from Tarkov, from [jabujabu.net](https://jabujabu.net).
It puts a small overlay over the game: item prices when you hover them, the value of the loot
you pick up in a raid, a task tracker and your income.

**It is in beta.** It is still being tested, so expect rough edges and the odd wrong number.
Prices and loot counts are estimates.

## Download

Get the latest version from the [Releases page](../../releases/latest):

- `TarJabu-Setup-<version>.exe` - the installer (recommended)
- `TarJabu-<version>-portable.zip` - the same app as a folder: unzip anywhere and run `TarJabu.exe`

The app is not code-signed yet, so Windows will show "Windows protected your PC" the first
time. Click **More info**, then **Run anyway**.

## What you need

- Windows 10 or 11
- The game running in borderless or windowed mode
- The game's interface in English, on a 16:9 screen

## Using it

TarJabu runs from the system tray (bottom right of the taskbar). Press **Ctrl+Shift+J** over
the game to unlock the overlay; the gear opens the settings. Your settings and history are
kept in `%APPDATA%\TarJabu` and survive updates and uninstalling.

## Disclaimer

TarJabu is a fan-made tool. It is not affiliated with, endorsed or approved by Battlestate
Games. It only reads your screen and the game's log files - it never reads or changes the
game's memory or files and never sends input to the game. Use at your own risk.

Item prices and task data come from [tarkov.dev](https://tarkov.dev), a community project.

This repository holds the downloads only.
